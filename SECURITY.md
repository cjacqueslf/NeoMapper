# Segurança

## Versões suportadas

Somente a versão mais recente publicada recebe correções de segurança.

## Relato responsável

Não publique vulnerabilidades com dados sensíveis em uma issue. Envie o relato
ao mantenedor pelo endereço `cjacqueslf@gmail.com`, incluindo versão, impacto,
passos mínimos para reprodução e uma forma segura de contato. Evite anexar
credenciais, chaves ou dados pessoais.

O projeto não solicita senha, token ou conta de usuário. Desconfie de pacotes
distribuídos fora da página oficial de Releases e confira o SHA-256 publicado.
